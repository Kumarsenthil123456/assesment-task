# Assessment Task – Hero Section UI

This project was created as part of an assessment task to build a clean and responsive Hero Section UI based on the provided Figma design.

## Tech Stack
- React
- Tailwind CSS

## Features
- Responsive Hero Section layout
- Glassmorphism badges (Courses, Rating, Happy Kids)
- Clean typography and spacing
- UI closely matched to the provided Figma design

## Folder Structure
- src/components – Reusable UI components
- src/assets – Images and icons
- App.js – Main layout
- index.js – Entry point

## How to Run Locally
1. Clone the repository  
   `git clone https://github.com/Kumarsenthil123456/assesment-task.git`
2. Install dependencies  
   `npm install`
3. Start the project  
   `npm start`
